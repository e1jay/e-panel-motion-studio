# Panel Motion Studio starter

This project has visible story writing, scene cards, character image upload, and a browser-based moving storyboard preview.

## Run it
Requires Node.js 18+. Extract the ZIP, open a terminal in the project folder, run:
1. `npm install`
2. `npm start`
3. Open `http://localhost:3000`

## Honest feature status
- Story-to-scene cards: connected.
- Character image upload: connected.
- Moving storyboard preview: connected; moves the uploaded image as a simple browser animation.
- AI character generation: not connected.
- Real AI-generated video: not connected. Requires a compatible video API, secure server integration, and potentially paid provider credits.
- Wallet/payment: not enabled; this prototype does not take payments.
- Do not place API keys in public code or share them in chat.
